# Tecnologias Web

Materiais das aulas de **Tecnologias Web**, ministradas pelo professor [Paulo Ricardo de Souza](https://github.com/pauloricardosouza).

## Conteúdo

Os arquivos atuais registram exercícios introdutórios de HTML e recursos da Web:

- `aula1.html` — estrutura inicial de uma página;
- `links.html` — links;
- `listas.html` — listas;
- `tabelas.html` — tabelas;
- `midias.html` — uso de mídias;
- `iframe.html` — iframe;
- `forms.html` e `forms2.html` — formulários;
- `semantica.html` — elementos semânticos;
- páginas de cores (`amarelo.html`, `azul.html`, `preto.html`, `rosa.html`, `verde.html` e `vermelho.html`);
- imagens e áudio utilizados nos exercícios.

## Organização

Os arquivos são mantidos próximos da forma utilizada em aula para facilitar revisão e comparação com os exercícios originais. Mídias necessárias para os exemplos podem permanecer neste diretório.

A licença do repositório aplica-se ao conteúdo autoral. Mídias de terceiros permanecem sujeitas aos direitos de seus respectivos autores.
