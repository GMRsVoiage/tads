# TADS — IFPR

Repositório acadêmico para acompanhar atividades, exercícios e projetos desenvolvidos durante o curso de **Tecnologia em Análise e Desenvolvimento de Sistemas (TADS)**.

O curso é organizado em seis períodos. Neste repositório, os materiais são agrupados principalmente por **ano** e **disciplina**, preservando os nomes originais das atividades quando eles ajudam a relacionar o código ao conteúdo passado em aula.

## Estrutura

- [2026](./2026/) — materiais acadêmicos de 2026
  - [Algoritmos e Programação II](./2026/Algoritmos%20e%20Programa%C3%A7%C3%A3o%20II/)
  - [Gestão de Websites](./2026/Gest%C3%A3o%20de%20Websites/)
  - [Jogos Digitais](./2026/Jogos%20Digitais/)
  - [Tecnologias Web](./2026/Tecnologias%20Web/)

Cada disciplina deve manter um `README.md` próprio com contexto suficiente para identificar professor, área estudada, tecnologias e organização dos arquivos.

## Convenções do repositório

- Priorizar **código-fonte e materiais necessários para estudo**.
- Não versionar artefatos gerados por compilação, como `.exe`, `.o`, `.obj` e `.class`.
- Manter os arquivos dentro de `<ano>/<disciplina>/`.
- Preservar nomes de atividades quando eles tiverem relação com a nomenclatura usada em aula.
- Atualizar o README da disciplina quando uma nova categoria relevante de conteúdo for adicionada.
- Evitar misturar, no mesmo diretório, arquivos de disciplinas diferentes.

As regras para ferramentas automatizadas e agentes de IA estão em [AGENTS.md](./AGENTS.md).
