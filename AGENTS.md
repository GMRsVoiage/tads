# AGENTS.md

Estas instruções se aplicam a todo o repositório e existem para manter o material acadêmico fácil de entender por pessoas e por agentes de IA.

## Objetivo

Este é um repositório de estudo. O objetivo principal é preservar atividades, exercícios e projetos produzidos durante o curso de TADS, mantendo contexto suficiente para que o conteúdo possa ser retomado no futuro.

## Regras de organização

1. Use a estrutura `<ano>/<disciplina>/`.
2. Cada disciplina deve possuir um `README.md` com contexto, tecnologias e uma visão geral dos arquivos.
3. Não misture materiais de disciplinas diferentes.
4. Não versione binários ou artefatos gerados por compilação.
5. Preserve nomes de exercícios e atividades quando eles correspondem à nomenclatura usada em aula.
6. Ao adicionar uma disciplina nova, inclua-a também no índice do respectivo ano e no README raiz quando relevante.

## Regras para alterações automatizadas

- Não "corrija", refatore ou reescreva soluções de atividades apenas por preferência de estilo.
- Só altere o conteúdo de uma atividade quando houver uma solicitação explícita para isso.
- Não remova exemplos aparentemente incompletos: eles podem representar o estado de uma aula ou exercício.
- Ao renomear ou mover um arquivo, atualize links e índices relacionados.
- Prefira mudanças pequenas, rastreáveis e com mensagens de commit que indiquem claramente o escopo.
- Antes de alterar uma disciplina, leia seu `README.md` e preserve o contexto acadêmico registrado ali.
- Depois de mudanças estruturais, verifique se os índices continuam apontando para caminhos válidos.

## Conteúdo de terceiros

Não presuma que imagens, áudios ou outros materiais de terceiros estão cobertos pela licença do código autoral do repositório. Preserve os avisos e direitos aplicáveis.
